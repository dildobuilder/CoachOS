Use this as the visual direction for the Sprint 1B calendar implementation.

## Key UX Notes

- The calendar should feel like a dense working timeline, not a decorative card list.
- Day view should make occupied and free time easy to scan.
- Time blocks should be visually aligned to a clear vertical timeline.
- Creating and opening events should feel quick and direct.
- Training events must remain the primary path into workout sessions.
- Desktop layout can use more horizontal space, but mobile must stay fast and readable.

## Sprint 1B Boundary

Do not implement a full Google/Yandex calendar clone in Sprint 1B. Build the minimum trainer-focused day view first:

- today's events;
- client training event creation;
- event status;
- start workout from event;
- simple reschedule/edit flow;
- clear visual time positioning.
